# N of One for Mac: downloads

This repository holds only the signed releases of N of One for Mac. Get the newest `.dmg` from [Releases](../../releases/latest).

The app checks this repository for updates. It installs an update only when the update is signed with N of One's Developer ID and matches its recorded checksum. It never updates past the version of the server it's connected to.

No source code lives here. Once the main N of One repository is public, the app will get updates from that repository's releases and this one will be archived.
